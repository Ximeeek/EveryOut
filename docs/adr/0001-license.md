# ADR 0001: License EveryOut under GNU GPL version 3 or later

- Status: Accepted
- Date: 2026-09-30

## Context

The root [README](../../README.md) and [LICENSE](../../LICENSE) identify the project as licensed
under the GNU General Public License version 3 or, at the recipient's option, any later version.
The project needs a license that permits people to use, share, and modify the program while
preserving those freedoms for redistributed modified versions.

The GNU GPL grants the freedoms to run, study, share, and modify covered works; its source and
redistribution terms support access to the corresponding source and continued freedom for
recipients. The GNU project's licensing guidance recommends GPL for most programs and recommends
the “version 3 or any later version” wording to allow later GPL versions. This matches the license
already recorded in the repository.

## Decision

License EveryOut under the GNU General Public License, version 3 or (at the recipient's option)
any later version, as recorded in the root `LICENSE` file. Keep README license references
consistent with that grant.

## Consequences

Redistribution and distribution of modified covered works must follow the GPL's terms, including
its applicable source availability and license notice requirements. Contributors and maintainers
must review third-party components for license compatibility before incorporating them. The
“or any later version” option lets recipients select a later GPL version when permitted by the
license text.
