# SessionWipe

SessionWipe is a Windows desktop application, currently in the pre-alpha design phase, intended to log the user out locally from apps and browser sessions with one click. The application is designed to delete session data; using it can remove access to accounts and destroy local-only data, so review its behavior carefully before use.
